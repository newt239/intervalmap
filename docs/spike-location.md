# M1 バックグラウンド位置検証スパイク 結果記録

expo-location + expo-task-manager 実装（[ADR-0001](adr/0001-background-location.md)）を iOS / Android 実機で検証し、結果をここへ追記する。**このドキュメントの合格基準を満たさない場合は Transistorsoft 移行を判断する**（handoff.md §8 M1）。

## 検証手順

1. `pnpm --filter @intervalmap/api dev` で API をローカル起動するか、デプロイ済み Worker を用意する。
2. `EXPO_PUBLIC_API_URL` を API の URL に設定して EAS Build した dev-client を実機へインストールする。
3. ホーム画面でセッションを作成（インターバル 1分・有効期間 1時間 推奨）し、「位置共有を開始」する。
4. 以下のチェックリストを実施し、結果と観察を記録する。

## チェックリスト

- [ ] フォアグラウンドで追跡開始 → 画面オフ・他アプリ操作で30分放置 → D1 に位置が届き続ける
- [ ] Android: ACCESS_BACKGROUND_LOCATION なし（フォアグラウンドサービスのみ）で上記が成立する
- [ ] iOS: Always 権限で上記が成立し、ステータスバーのインジケータ挙動を記録
- [ ] `expires_at` 到達でクライアントが自走停止し、サーバーも以降のアップロードを拒否する
- [ ] 電池消費の実測（1時間あたり%）を記録
- [ ] 端末の省電力モード・Doze 下での挙動を記録
